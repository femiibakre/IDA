# International Development Assistance (IDA)

> **Creating Opportunities. Supporting Lives.**

A landing page for the **International Development Assistance (IDA)** philanthropic initiative.

## Overview

The International Development Assistance (IDA) program provides financial support starting at $25,000+ to eligible individuals and families facing financial challenges.

### Key Sections
- **Hero**: Mission tagline, animated particles, and key program metrics.
- **About IDA**: Program pillars (Financial Relief, Education, Business Development, Livelihood).
- **Eligibility**: 6 qualifying categories (Low-Income Families, Entrepreneurs, College Students, Retirees, Senior Citizens, Individuals with Disabilities).
- **Financial Assistance**: Breakdown of potential support ($25,000+ starting).
- **Mission & Vision**: Organizational values and community impact.
- **Contact**: Direct contact card for Program Agent **Sheinetta Bell** with official email channels.

## Technologies Used
- HTML5 (Semantic & Accessible)
- Vanilla CSS3 (Custom Design Tokens, Flexbox, CSS Grid)
- Vanilla JavaScript (IntersectionObserver scroll animations, mobile drawer, floating particles)
- Typography: Inter via Google Fonts
